# kogda-igra-net

Порт сайта [kogda-igra.ru](https://kogda-igra.ru) — календаря ролевых игр (LARP) — с PHP на
ASP.NET Core 10.

Оригинал живёт в отдельном репозитории (`leotsarev/kogda-igra`) и остаётся источником истины по
поведению до конца миграции. Порт делается «1=1»: сначала буквальное повторение поведения, потом
нормальная архитектура.

## Статус

Ранняя стадия. В репозитории пока есть только **compat-харнесс** — тестовый проект
`src/KogdaIgra.CompatTests`, который поднимает PHP-версию в Docker вместе с Postgres и гоняет по ней
тесты. Самого портала на ASP.NET Core ещё нет.

Схема БД (`db/`) сконвертирована из legacy-дампов PHP-репозитория и накатывается тестами на чистый
Postgres.

## Быстрый старт

```bash
dotnet build
dotnet test     # нужен Docker и переменная KOGDA_IGRA_IMAGE
```

Образ PHP-версии приватный, поэтому перед первым прогоном его надо собрать локально — пошагово в
[docs/compat-tests.md](docs/compat-tests.md).
