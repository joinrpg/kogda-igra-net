## Команды

```bash
# Сборка
dotnet build

# Стиль кода (обязательно перед коммитом)
dotnet format

# Проверка стиля, как в CI
dotnet format --verify-no-changes --severity warn

# Тесты (нужен Docker; про KOGDA_IGRA_IMAGE — см. compat-tests.md)
dotnet test
```

## Обновление документации

1. Определите, нужен ли новый документ или достаточно дополнить существующий.
2. Новое архитектурное решение оформляется отдельным ADR (Статус / Контекст / Решение /
   Альтернативы и почему отклонены / Последствия).
3. Добавьте ссылку в этот README.
4. Убедитесь, что документ соответствует текущему состоянию кода.
